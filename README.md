# 🔍 Python Port Scanner

A cybersecurity tool developed using Python to perform basic network reconnaissance by scanning open ports on a target system.

---

## 🚀 Features
- Scans ports in a defined range
- Detects open ports on a target machine
- Identifies common services (HTTP, SMB, RPC, etc.)
- Simple and lightweight tool for beginners in cybersecurity

---

## 🛠️ Technologies Used
- Python
- Socket Programming
- TCP/IP Networking

---

## ▶️ How to Use
1. Run the script:
   python port_scanner.py
2. Enter target IP (e.g., 127.0.0.1)
3. View open ports and services

---

## ⚠️ Disclaimer
This tool is created for educational purposes only. Use it only on systems you own or have permission to test.
